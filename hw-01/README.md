# Домашняя работа 1 — Infrastructure as Code

Стенд для демонстрации продукта клиентам.

## Состав стенда

- собственная сеть;
- две подсети в разных зонах доступности;
- два веб-сервера за сетевым балансировщиком;
- отдельный сервер приложения без публичного IP;
- NAT Gateway и таблица маршрутизации для доступа закрытого сервера в интернет.

## Параметры варианта

- Prefix: kuzmin-01
- Zone A: ru-central1-a
- Zone B: ru-central1-b
- Subnet A: 10.11.1.0/24
- Subnet B: 10.11.2.0/24
- Service port: 8003
- Greeting: labwork
- Web servers: 2
- Environment: lab

## Создание стенда

Обычный запуск:

    bash hw-01/create.sh

Количество веб-серверов можно изменить аргументом:

    bash hw-01/create.sh --web-count 3

Также доступны параметры:

    bash hw-01/create.sh --prefix my-prefix
    bash hw-01/create.sh --env test

Приоритет параметров:

1. аргумент командной строки;
2. переменная окружения;
3. значение варианта по умолчанию.

Пример:

    WEB_COUNT=4 bash hw-01/create.sh --web-count 3

В этом случае будет использовано значение `3`.

## Проверка стенда

Запуск проверки:

    bash hw-01/check.sh
    echo $?

Код возврата:

- `0` — все проверки прошли;
- `1` — одна или несколько проверок не прошли.

Скрипт `check.sh` проверяет:

1. доступность балансировщика по HTTP;
2. ответы более чем от одного веб-сервера;
3. доступность сервера приложения из внутренней сети.

Если `check.sh` вернул `1`, необходимо проверить:

- состояние виртуальных машин;
- состояние nginx;
- health check балансировщика;
- сетевую связность между web-сервером и app-сервером.

## Удаление стенда

Запуск удаления:

    bash hw-01/destroy.sh

Скрипт ищет ресурсы стенда по префиксу и удаляет их с учётом зависимостей.
